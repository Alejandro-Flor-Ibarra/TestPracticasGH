# 🚀 StreamFlow

Sistema de monitoreo y operaciones matemáticas desarrollado con Node.js.

---

## 📌 Descripción

**StreamFlow** es una aplicación que permite:

- Ejecutar operaciones matemáticas básicas
- Realizar monitoreo del sistema (healthcheck)
- Servir como base para proyectos en Node.js

---

## ⚙️ Tecnologías usadas

- Node.js
- JavaScript (ES Modules)
- npm
